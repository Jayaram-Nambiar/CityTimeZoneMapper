# Contributing

Thanks for your interest in improving City Timezone Mapper.

## Development setup

Follow the local setup instructions in [`README.md`](README.md).

## Before opening a pull request

1. Keep changes focused and documented.
2. Run the verification commands listed under **Verification** in the README.
3. Do not commit secrets, `.env` files, virtualenvs, `node_modules`, or agent/
   IDE scratch files (`.cursor/`, `.agent-context.json`, etc.).
4. Update [`THIRD_PARTY_NOTICES.md`](THIRD_PARTY_NOTICES.md) if you add
   dependencies or data sources.
5. Prefer `zoneinfo` + `tzdata` for any new Python timezone examples.

## Code of conduct (short)

Be respectful in issues and pull requests. Harassment or abuse is not welcome.
